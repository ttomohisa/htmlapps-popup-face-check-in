Pop-up Face Check-in
====================

日本語

1. 配布用ZIPを展開し、dist/index.html をブラウザで開きます。単体の
   HTMLをダウンロードした場合は、そのファイルを直接開きます。
   どちらもランタイムとモデルを内包しています。
2. 言語、受付または入退場、保存期間を選び、取扱い上の注意を確認します。
3. 「登録」で「写真で登録」または「名前で登録」を選びます。
   カメラを使えない場合も、「受付」から名前で手動受付できます。
4. 終了時は「履歴」→「受付を終了」で必要な履歴を保存し、削除内容を確認します。
   出力したファイルが不要になったら、別途削除してください。

詳しい操作は README.ja.md、外部コンポーネントのライセンスは
THIRD_PARTY_NOTICES.md にあります。

English

1. Extract the distribution ZIP and open dist/index.html in your browser.
   If you downloaded the individual HTML file, open that file directly.
   Both include the runtime and models.
2. Select a language, choose Check-in or Entry / exit, select a retention
   period, and acknowledge the data-handling precautions.
3. Open Register and choose By photo or By name. If a camera is unavailable,
   open Check in and use manual check-in by name.
4. When finished, open History > Finish session to save any history you
   need and review the data to delete. Delete exported files separately.

See README.md for instructions and THIRD_PARTY_NOTICES.md for the licenses
of the embedded components.
