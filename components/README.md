# Reusable components

These files mirror the reusable component layer from `htmlapps-template`.
Copy/adapt the relevant CSS, markup, and script into `src/index.template.html`; the release remains dependency-free at runtime.

- `toast.html`: reversible action + Undo
- `confirm-dialog.html`: destructive/high-risk confirmation
- `popover-menu.html`: compact overflow menu
- `setting-field.html`: preset/custom numeric settings
- `async-state.html`: stale async result guard
- `mobile-bottom-bar.html`: smartphone fixed bottom navigation/action bar
